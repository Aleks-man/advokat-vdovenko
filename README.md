# Константин Вдовенко — сайт адвоката

Делаю сайт-визитку для друга — адвоката Константина Вдовенко. Основная специализация — уголовные дела.

Сейчас в проекте четыре страницы: главная, уголовная защита, подход к работе и контакты. По дизайну — спокойная палитра, крупная типографика и минимум лишних элементов. Вёрстка адаптирована под компьютер и телефон.

## Стек

- **Frontend:** React, TypeScript, Vite, React Router, Lucide.
- **Backend:** Node.js, Express, TypeScript.
- **База данных:** PostgreSQL — подключение подготовлено на будущее.
- **Инструменты:** npm workspaces, Prettier, Playwright.

Бэкенд добавил сразу, чтобы дальше было куда развивать админку и работу с данными. Пока есть health endpoint, база для запуска не нужна. Формы отправки обращений ещё нет.

## Локальный запуск

Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

- Сайт: http://127.0.0.1:5173
- API: http://127.0.0.1:3001/api/health

Оба приложения запускаются одной командой из корня.

## Структура

```text
front/src/
  app/          — маршрутизация и каркас приложения
  components/   — блоки сайта, у каждого свой CSS
  pages/        — страницы
  data/         — контент и настройки сайта
  styles/       — общие стили и переменные

back/src/
  config/       — настройки окружения
  db/           — подключение PostgreSQL
  routes/       — маршруты API

tests/browser/  — браузерные проверки
```

Контакты, навигация и направления работы лежат в `front/src/data/site.ts`. Цвета, шрифты и общие размеры — в `front/src/styles/tokens.css`.

## Команды

```sh
npm run typecheck     # проверка TypeScript
npm test              # тесты API
npm run test:browser  # браузерные проверки
npm run build         # сборка front и back
npm run format        # форматирование
npm run format:check  # проверка форматирования
```

Для браузерных тестов нужен установленный Google Chrome. Настройки — в `playwright.config.ts`. Скриншоты сохраняются в `artifacts/` и не попадают в Git.

## База данных

Когда понадобится база, настройки подключения будут в `back/.env` — пример есть в `back/.env.example`. Подключение использует `DATABASE_URL`. Схему и миграции добавлю под конкретные задачи.

## Работа с Git

Основная ветка — `main`. Каждую задачу веду в отдельной ветке: изменения, проверки, коммит, слияние в `main`, удаление рабочей ветки. Слияния — через `--no-ff`, чтобы история задач сохранялась.
