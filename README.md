# Константин Вдовенко — сайт адвоката

Сайт адвоката по уголовным делам: главная, направления защиты, биография и контакты.

## Стек

- Фронтенд: React 19, TypeScript, Vite 6, React Router 7, Lucide.
- Стили: CSS, адаптивная вёрстка, общие переменные цветов, размеров и типографики. Onest поставляется локально, Georgia используется как системный шрифт.
- Бэкенд: Express 5, TypeScript, заготовка подключения PostgreSQL через `pg`.
- Проверки: Playwright, Node.js Test Runner, Supertest, Prettier, GitHub Actions.
- Организация репозитория: npm workspaces (`front`, `back`).

## Разработка

Node.js 20.19+ или 22.12+. CI использует Node.js 22.

```sh
npm ci
npm run dev
```

Фронтенд: http://127.0.0.1:5173. API: http://127.0.0.1:3001/api/health.
Vite проксирует локальные запросы `/api` на бэкенд.

## Структура

```text
front/src/
  app/          — маршрутизация и эффекты переходов
  components/   — общие компоненты
  pages/        — страницы и их локальные компоненты
  data/         — контент и контакты
  styles/       — базовые стили, раскладка, общие элементы и переменные
  assets/       — изображения и графика

back/src/
  config/       — конфигурация окружения
  db/           — подключение PostgreSQL
  routes/       — маршруты API

tests/browser/  — браузерные тесты
```

Компоненты хранятся вместе со своими стилями. Блоки отдельной страницы находятся в `pages/<Page>/components/`, переиспользуемые — в `components/`.

Общие данные — в `data/`. Тексты страницы «Обо мне» — в `pages/About/data/`: биография (`about.ts`), вопросы и ответы (`faq.ts`), этапы работы (`workSteps.ts`). Пути страниц, заголовки вкладок и навигация определены в `app/routes.ts`, контакты — в `data/site.ts`, сведения об адвокате — в `data/attorney.ts`.

Общие стили разделены на `global.css` (базовые элементы и типографика), `layout.css` (контейнеры и секции) и `ui.css` (кнопки, ссылки и оформление). Цвета, размеры и отступы заданы в `tokens.css`.

## Проверки

| Команда                | Назначение                                        |
| ---------------------- | ------------------------------------------------- |
| `npm run typecheck`    | Типы приложений, тестов и конфигурации Playwright |
| `npm test`             | Тесты API                                         |
| `npm run test:browser` | Браузерные тесты в Google Chrome                  |
| `npm run build`        | Сборка обоих приложений                           |
| `npm run format:check` | Проверка форматирования                           |
| `npm run format`       | Форматирование                                    |

GitHub Actions выполняет проверки при push и pull request. Браузерные тесты запускаются отдельным заданием; отчёты об ошибках, трассировки и скриншоты хранятся в артефакте `browser-test-report` 7 дней. Конфигурация CI — `.github/workflows/ci.yml`.

## Бэкенд

Доступен `GET /api/health`; PostgreSQL для его работы не требуется. Пул соединений создаётся при обращении к базе. Параметры `PORT` и `DATABASE_URL` читаются из окружения; образец — `back/.env.example`.

## Развёртывание

На Vercel публикуется фронтенд. Конфигурация в `vercel.json`: корень репозитория, установка через `npm ci`, сборка `npm run build -w front`, результат — `front/dist`. Бэкенд развёртывается отдельно; фронтенд пока не использует API.

Маршруты обрабатываются как SPA с fallback на `index.html`. Адрес `/approach` перенаправляется на `/about`. Неизвестные адреса показывают страницу 404 внутри приложения, HTTP-статус fallback-ответа — 200.
